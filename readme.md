This is a complete replication of Keysoft 9.5.1 as seen on the BrailleNote Apex, reverse engineered and patched to run on Windows.

It was written for nostalgia. I and many others grew up using this device, which has since been discontinued. The last one I have is stuck on a boot loop at the bottom of a box somewhere in my home office. My objective was to see how close I, with the help of Claude, could get to making the drivers run on modern hardware.

## What works

Everything that was supported on the original device is supported here.
I am using the same kernel that ran on the original device, which I obtained by unpacking an update file.
Humanware has entirely discontinued support for the BrailleNote Apex line.
